# Support

## Getting help

For usage questions and reproducible bugs, search the existing
[GitHub issues](https://github.com/weiran/Hackers/issues) first. If no issue exists,
open one with a clear title and enough context to reproduce the problem.

For contribution and setup questions, read:

* [Contributing](CONTRIBUTING.md)
* [Development guide](docs/development.md)
* [Project overview](docs/project-overview.md)

## Bug report details

Include the app version, iOS version, device, reproduction steps, expected result,
actual result, and screenshots or logs where useful. Remove usernames, cookies,
tokens, URLs containing private data, and other sensitive information.

## Security issues

Do not use public issues for security reports. Follow [SECURITY.md](SECURITY.md).

## Scope

Hackers is a volunteer-maintained open-source project. Support is provided on a
best-effort basis; a response or fix cannot be guaranteed for every request.
